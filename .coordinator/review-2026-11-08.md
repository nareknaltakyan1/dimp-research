# Code review findings (2026-11-08, read-only reviewer)

Fix AFTER the experiment matrix completes (fixes change benchmarked binaries).
Then re-run E1 + E6 for s5-fdpass and s7-inplace to confirm the numbers did not change.

## High
1. S7 downgrade/replay: `rollback`/`reconcile` flags come from the unsigned request body
   (cmd/s7-inplace/server.go:466); signing.go:238-243 admits any older signed bundle; "current"
   is in-memory only and resets to v1 on restart; Policy.MaxAge never set (server.go:382).
   Fix: persist a high-water mark; restrict rollback to the retained previous digest; set MaxAge.
2. S7 admin endpoints fail open: -admin-addr defaults to the public port, no token means auth is a
   no-op (main.go:44,86; server.go:192-199,223); /admin/upgrade passes Reconcile:true
   unauthenticated (server.go:575); S6 admin has no auth (cmd/s6-hotpatch/main.go:125-148).
   Fix: refuse to start admin endpoints without a token unless bound to loopback / explicit -insecure-admin for the bench.

## Medium
3. canary Abort can be lost during promotion (canary.go:426-437, 571-577); the operator ignores
   the abort response (podclient/client.go:162-165; hotpatch_controller.go:469-473) -> mixed fleet reported RolledBack.
4. Operator rollback can stall forever: FromVersion=d.Stable set before the already-patched branch
   (hotpatch_controller.go:339-346,455); transient loadBundle error is terminal (236-242); a 409 is terminal PodRejected (416-419).
5. S5 handoff race: unbuffered waiter channel + non-blocking send (internal/handoff/upgrader.go:343,309-314)
   -> successor rejected "upgrade already in progress" under CPU load. Fix: buffer 1.
6. S5 rollback after the successor served; external -takeover successor is not killed (cmd==nil, upgrader.go:397)
   -> two servers with overlapping counts. Fix: do not resume unless the peer is confirmed dead; child accepts only after ready-ack.
7. patchable stale pinned ctx: Enter does no recheck (registry.go:388-392,314-318); Pin on a stale ctx re-increments a pruned set.
   Fix: Unpin invalidates the ctx (generation check) and Enter rechecks against live.
8. canary finish() writes into the NEXT rollout's struct (canary.go:483,492,521-523). Fix: capture *Rollout.
9. hotswap Rollback/Verify may republish an impl already Unload()-ed (S3 module closed)
   (registry.go:259,299; svc.go:242-248); ErrVerify leaves r.prev = the failed version.

## Low
- S6 delivery: no replay/downgrade/expiry; private .so copy leaks in the cached case.
- S7 check-then-start not atomic (server.go:382 vs 397); followRollout updates current/previous asynchronously.
- handoff recvChunk leaks FDs on MSG_CTRUNC / ParseUnixRights error (fdpass.go:53,68-71); no runtime.KeepAlive after f.Fd().
- svc.go:228-235 emits upgrade_failed on drain timeout (contract says it is the rollback event) -> may misclassify E3 runs.
- stripeOf hash may cluster stripes (scalability only; uncertain).
- patchable.Revert ErrNotTop if Register/SetBaseLabel replaced cur (uncertain).

S5 Seal arithmetic (count + inflight exact); wasmguest shadow pool separation.
